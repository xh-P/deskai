# 制作 Live2D 角色

从用户本轮的选型和阶段验收要求开始。记录正面站姿、衣装、鞋、默认道具、画风、允许重做的范围。后续涉及这些选择时优先使用用户确认的图。需要阶段确认时，提供能比较的图或整轮预览，并保留前一轮的可编辑工程。

## 参考与生图

1. 读参考角色的官方 CMO3、CAN3 和运行时文件。列出实际 ArtMesh、原画来源、绘制顺序、遮挡和变形器父链。区别绘画图层、网格、变形器、运动曲线、摆锤和切换图。一个部位有多个运动控制时仍可能只用一张连续的原画。
2. 在同一镜头量站姿。用中立头顶到鞋底或裙边到鞋底作比例基准，记录膝距、鞋间空隙、两脚接地高度、鞋面透视和左右对应。播放动作时跟踪固定的网格顶点。侧移、局部转向和物理要各自隔离一次。
3. 用 ImageGen 先出全身完整稿。明确角色、画风、相机、站姿、服装和光向的参考，按实际轮廓、比例与遮挡筛图。以选中的完整稿为参考，生成有完整遮挡底稿的分件，再拆成可编辑图层。保留全身原件、入选分件、生成提示和真实 alpha。可见细节可从完整稿或对应的生成部件拆出。
4. 左右鞋、手、袖、发束等都用各自生成的画面。成对生图时给每侧独立轮廓、透视和同一个画面光向，拆件时记录取图位置和角色左右。禁止靠镜像、复制另一侧或程序涂画来补素材。重合、配准、透明裁切和网格变形按同侧原画处理，缺画的遮挡区交给生图模型补齐。

## 分层、绑定与导出

1. 统一 PSD 画布、坐标和命名。给每层记录图层 ID、角色自身左右、默认可见性、绘制层次、裁切目标和连接区。用透明预览检查露出的皮肤、衣褶、发根和道具，分别合成中立、闭眼、口型、眼镜与关键姿态。先重开 PSD 核对实际图层和位置。
2. 导入 PSD 或在既有可编辑工程上替换指定 ArtMesh。按参考建立变形器层级。旋转关节及其子部件用独立枢轴，连续膝形用整条腿网格和局部关键形，软料用固定边与物理摆锤。眼球等使用现有裁切，眼镜等装饰单独控制可见性。
3. 做中立、单轴极值和组合姿态。检查接缝重叠、穿帮、脚底稳定和近远透视，再做待机、表情、动作时序。复用用户确认过的动画节奏时保留兼容参数 ID。在镜头固定的完整循环里核对速度、相位和遮挡。[站姿待机调校指南](../../../docs/desktop-voice/live2d-standing-idle-guide.md)
4. 保存原始可编辑工程、Cubism CMO3 与 CAN3，导出匹配运行时版本的 MOC3、贴图、模型清单、表情、物理与动作。重开工程、检查资源引用，并用应用实际运行的 Core 核对模型。PSD2Live 的操作和回读检查见 [PSD2Live 制作与验证](reference.md)。
5. 将特定模型的标签、可编辑运动、物理与形变能力放进模型侧车。用真实 ArtMesh 和参数 ID 核对配置，在应用中试点选、网格、参数调整、保存与重开。优先保留可由标准 Cubism 模型读取的参数与 Part 信息。

## 每轮记录

用短 Markdown 放上成稿、关键层与关键帧。记录每个绘画层对应的生成图或完整稿局部，以及层、绑定、导出和预览的对应关系。涉及左右件的改动时，从实际运行时抓同镜头的近景检查光向、鞋距、接缝和透视。下一轮沿用已确认的素材与工程，从用户指出的时间和部位继续。[本项目的图文记录](../../../docs/desktop-voice/nagato-live2d-production.md)
