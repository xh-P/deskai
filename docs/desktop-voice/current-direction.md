# 当前项目方向

更新：2026-11-04。用户明确撤销此前写入项目文档的产品范围和技术路线要求。当前目标是获得更好的实际使用效果，并逐项拆解 Amadeus 的技术方案、选择有效部分学习到 DeskAI2。

## 已撤销的旧约束

以下旧要求不再构成实现边界：

- 固定使用 dsh SenseVoiceSmall → dsh 对话 → GPT-SoVITS v2，或固定某一版本、声音、人格作为后续默认值。
- 固定自动监听、断句、插话、回声处理、选择性回应等首版范围或交互规则。
- 固定使用 SPEAK / WAIT / SILENT、一次 LLM 调用、不增加判断调用等协议和调用约束。
- 禁止长期记忆、限制主动行为，或规定人格、声音、语言如何拆分。
- 按旧 M0–M5 执行顺序、门禁和验收范围推进。
- 旧版 AGENTS/协作文档里针对子 Agent 模型与调度的项目要求。

以上内容在旧文档中保留为历史背景、当前实现描述或旧验证记录；不能据此否决用户后续提出的更好效果方案。它们也不证明对应功能在当前代码中已经存在。

- 以用户实际体验为主要目标；用户已报告 Amadeus 在延迟、角色动画、人格/记忆和桌面呈现方面更好。
