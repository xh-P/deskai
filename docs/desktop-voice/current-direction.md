# 当前项目方向

更新于 2026-11-12。当前目标是把 Amadeus 已实现的能力逐项整合进 DeskAI2，以实际使用效果决定取舍。进度见[Amadeus 整合任务清单](./optimization-backlog.md)。

## 已撤销的旧约束

用户于 2026-11-04 撤销此前写入项目文档的产品范围和技术路线要求。以下旧要求不再构成实现边界：

- 固定使用 dsh SenseVoiceSmall → dsh 对话 → GPT-SoVITS v2，或固定某一版本、声音、人格作为后续默认值。
- 固定自动监听、断句、插话、回声处理、选择性回应等首版范围或交互规则。
- 固定使用 SPEAK / WAIT / SILENT、一次 LLM 调用、不增加判断调用等协议和调用约束。
- 禁止长期记忆、限制主动行为，或规定人格、声音、语言如何拆分。
- 按旧 M0–M5 执行顺序、门禁和验收范围推进。
- 旧版 AGENTS/协作文档里针对子 Agent 模型与调度的项目要求。

以上内容在旧文档中保留为历史背景、当前实现描述或旧验证记录；不能据此否决用户后续提出的更好效果方案。它们也不证明对应功能在当前代码中已经存在。

## 当前做事方式

- 本轮继续源码迭代，不制作目录包或安装包；完成一轮后提交并推送。遇到网络或授权阻塞，记录实际结果，不把本地提交称为推送成功。
- 不要求兼容旧数据、旧接口或旧设计；不为它们增加迁移和回退层，无用实现可直接删除。历史文档仅保留有价值的决策与验证证据。
- TTS 保持 v2；Qwen 显存保持驻留。中文和日语的长门、有希、长门有希为可修改默认唤醒词。
- AEC 继续对照 Amadeus，提供真实可选处理档位；参考其架构建立自己的 Host 工作控制层，由 AI 调用 DeepSeek Harness 执行任务，默认自动审查，不另造工具执行系统。执行器先只接 dsh，应用协作与执行权限分离。
- 独立 Host、执行恢复和工作区交付见[本轮实施记录](./host-work-20261112.md)，历史资料从[文档索引](./README.md)访问。当前 Agent 工作方式以[项目级 Agent 指引](../../AGENTS.md)为准。
- Work 完成评估、人工验收和 AUIP v0 应用见[实施与验证记录](./work-review-auip-20261112.md)。
- 对话候选、选择卡和持久操作回执见[实施与验证记录](./work-control-20261112.md)。
- 角色编辑、会话归属与《消失》角色知识库已接入，见[实施与开关对照](./character-knowledge-20261112.md)。视觉工作暂缓，后续方向为主播式 Live2D。
- AEC 与插话改造、模拟验证及待实机确认项见[语音稳定性实施记录](./voice-stability-20261111.md)。

- 以用户实际体验为主要目标；用户已报告 Amadeus 在延迟、角色动画、人格/记忆和桌面呈现方面更好。
- 一次拆解一个能力，先确认 Amadeus 当前公开代码如何实现，再和 DeskAI2 当前代码对照，随后提出并落地有明确效果目标的改造。
- 旧栈、旧协议和旧首版范围都可以调整；以实测结果决定取舍，不将公开 README 的描述代替代码证据，也不以 DeskAI2 的旧约束作为默认否决理由。
- 旧文档里的测试报告仍可作为“过去做过什么”的事实证据；不能直接当成新目标的验收标准。
