# Live2D 站姿待机调校指南

这份指南随样片迭代。每轮保留同一取景的旧版与新版，记录采用的调整、实测结果和用户反馈。其他角色可以复用测量和绑定步骤，幅度与节奏按角色的画风、服装和站姿定。

## 先量参考模型

1. 固定镜头和比例。记录画面方向与角色左右的对应关系。以下用画面左、右描述位移，用角色自身左右描述 `L/R` 参数。正面时角色左侧在画面右边。
2. 对照 CMO3 的父子变形器与 CAN3、MOTION3 的时间。分别播放动作关键帧、加物理后的动作，以及运行时自带的呼吸和视线。分别关掉身体 X/Y/Z、面部 X/Y/Z 和手臂轨道，确认每个控制对实际画面的贡献。
3. 追踪胸前、头部承载点、鼻子相对头部的位置、左右肩肘腕、髋、大腿、膝、小腿和鞋底。每个测点在中立形态选好网格顶点，整段沿用同一组。报告峰峰值和峰值时间。跨模型比较时除以静止全身高度。头的平移从承载点读，脸的朝向看局部网格与特征点。
4. 用相同的参照线对比中立、加载、极值和释放帧。检查完整速度的循环，也单独检查拐点、接缝和遮挡。

## 建立动作

- **支撑与重心**。从鞋底接触线确定站立点。把髋和躯干的横移、纵向起落、侧倾和透视转向作为可单独判断的量。鞋口可以随脚踝微调，鞋底作为固定测量基准。调整腿部时从髋和大腿向膝传递，膝下逐渐减弱，到鞋口归零。固定腿内侧时注意正视轮廓、裙下遮盖和两膝之间的空隙。
- **身体与头部**。侧移使上身带着颈根走。转向由胸前、衣领、衣襟和近远两肩的关键形改变轮廓。锁住重心轨道再拨身体 X，观察两肩的相对高低和两侧衣领的宽窄，检查左右转向的关键形。头部位置可以随身体，脸在这个位置上独立转向或微倾。把视线、眨眼和呼吸错开放入循环，检查脸朝向和眼睛方向的组合。
- **肩肘与袖口**。两条手臂各用肩 → 肘 → 腕。以各自肩为基准检查向内、向外，胸口的共同位移要另算。肩先启动，肘随后增加转角，近身一侧与远身一侧可以错开数帧。窄袖口随前臂一起转，手掌保持结构。关节附近可补袖形并保留重叠，跨较大角度时检查是否需要 Glue 或备用手势。
- **次级摆动**。先关物理验收身体、关节和鞋底，再开物理检查发根、发尾、领结、裙摆和袖面。软层末端可稍迟于驱动，固定边、袖口和贴身边缘要保持连接。用实测位移调整幅度，并检查发影、遮罩和共享摆锤的层。

## 检查一轮

- 播放至少两个完整循环，用相机固定的全身和手脚近景查看。检查回到第一帧时的位置和速度，检查腿脚是否滑动，以及肩、肘、腕有无断缝或手指尺寸变化。
- 保持相同参数，核对编辑器导出与实际运行时。在关键时间点检查脚、膝、头、手的位移与方向，再试动效幅度上限、暂停和单轴姿态。轨道关闭时检查同组与相邻部位是否仍能正确跟随。
- 将动态预览与三到五张有时间标记的关键帧一起交给使用者。反馈优先指明时间、画面方向和部位，再做局部调整。

## 第一轮参考数据

虹色真央 SDK 的 `mtn_01` 约 5.57 秒。使用 60 Hz 采样，先关闭额外呼吸与物理。以下为固定取景下的水平峰峰值，占静止时帽顶到鞋底高度的比例。

- 胸前中心约 1.68%，头部承载点约 3.40%。画面向右的峰值分别在约 1.07 秒与 1.23 秒。鼻子相对头部的向左极值约在 1.63 秒。这个时序下头先被带走，局部脸向在之后达到极值。
- 左右大腿约 0.42% 和 0.36%，膝约 0.43% 和 0.37%，小腿约 0.23% 和 0.19%，两侧鞋底最低一带横移均小于 0.004%。鞋和腿共用部分身体 X/Y/Z 绑定。
- 关掉身体只采肩肘腕，角色左肘的水平行程约 0.54%，左腕约 1.41%。肩与肘独立转，常见肘部关键帧比肩晚约八帧。腕的独立角度在这段待机保持中立。
- 身体转向的视觉来自身体 X/Y/Z 网格，叠加头颈位置和面部朝向。主待机用同一套 A 手势网格，手势切换由其他动作的 Pose 控制。参考样例还有程序化呼吸，比较原始曲线时将其单独关掉。[虹色真央官方工程](https://www.live2d.com/en/learn/sample/niziiro-mao/) · [Cubism 身体动作](https://docs.live2d.com/en/cubism-editor-tutorials/deformer/) · [变形器结构](https://docs.live2d.com/en/cubism-editor-manual/deformer/)

## 长门常服第一轮

- **动作时间**。一轮 5.60 秒。画面左、右肩在 0.42 / 0.50 秒后向内收，画面左、右肘在 0.62 / 0.69 秒后跟上。重心在 1.78 秒到最右，两肘约在 1.80 / 1.91 秒分别到顶，脸向左转在 1.96 秒到顶。双臂在约 3.7 秒向外回摆。循环起点和末尾回到中立。
- **位移**。测点固定在模型网格上。1.78 秒胸前约右移 20 画布像素，头部承载约右移 16 像素，鼻子在头的局部坐标约向左 1.6 像素。画面左、右两腕相对胸前约向内走 23 / 21 像素，两膝向内约 6.5 / 10.3 像素，两小腿约 2.5 / 3.7 像素。整轮鞋面最大变化低于 0.17 像素，鞋底横移低于 0.001 像素。
- **躯干转向**。对照相同重心、相同镜头的两个版本，在身体 X 加了一层肩部透视网格。侧移到顶时，两侧领肩测点额外错开约 3.2 画布像素，颈部和髋部的变化向边缘衰减。右侧大腿中段同步修了收腿曲线，在这一帧向内约 4.5 像素。
- **回读与接缝**。在 PSD2Live 与 CMO3 回读同一组姿态，按运行时网格和贴图检查肩、肘、袖口、手腕、颈口、裙下、袜口、鞋口。先测默认整轮，再抽检 1.6 倍的身体、手臂、腿部幅度。最后打开物理，侧发、前臂袖面、开衫、裙摆在重心到顶后陆续到位。
- **下一轮怎么比较**。保留 0.00、1.78、1.96 和约 3.7 秒的同镜头画面。反馈时记下时间、画面左或右、看全身还是近景。先处理接缝、落脚和方向，再微调最抢眼的部位。

## 长门常服站姿重绘

真央的腿部原画从大腿一直画到袜脚，膝部通过连续网格与 Deform Path 调整。长门按这一结构重绘了中立腿线，分开两只鞋。以裙边至鞋底为基准，鞋底支点中心距为 26.9%，鞋间最窄空隙为 16.3%。沿用这一轮的 5.60 秒动作曲线时，重新测量了膝部与鞋底，并把上身原有比例轴两端纳入接缝检查。[图文制作记录](./nagato-live2d-production.md)
