# 独立 Host、执行恢复与交付

2026-11-12 临时报告。对应 Amadeus 整合清单的 C、D、E，源码对照基准为 `be9b97a`。[任务清单](./optimization-backlog.md#c-独立-host) · [上游源码基准](https://github.com/Code-Amadeus/Amadeus/commit/be9b97aef2ac3affb200998f8af3aab72aa22f6c)

## 实际完成

- **C** 由独立 Node Host 管理 Work 账本、dsh 进程、产物登记和应用会话。桌面和命令行共享本机鉴权 API。桌面订阅状态更新，退出时断开自己的连接。Host 在绑定状态目录的监听端口后才加载账本，避免同一目录出现两个写入者。[Host 入口](../../apps/host/src/server.ts) · [本机鉴权](../../apps/host/src/api.ts)
- **D** 在发送 dsh 请求前保存会话、起始游标和请求 ID。重连时先接入快照，再用 `session/page` 补齐快照窗口以前的缺口。按原生 `user/message.source.rpcId` 绑定到 turn，用 `turn/end` 更新原 Attempt。无法确认终态时显示状态未知，并保留工作区供重新连接。dsh 报告工具结果未知时保留该信息，由用户决定下一步。[dsh 适配](../../packages/dsh-adapter/src/work-provider.ts) · [历史补齐](../../packages/dsh-adapter/src/session-feed.ts)
- **E1** Git Work 从项目已提交的 `HEAD` 建立独立任务分支与 worktree。继续或重试沿用绑定目录。源目录的未提交内容留在源目录。非 Git 或无提交项目使用原目录，同一 Host 内的重叠目录只允许一个执行持有写入权。[工作区准备](../../packages/work-core/src/workspace.ts)
- **E2** 用临时 Git 索引记录执行前后的树并按 Attempt 查看统一 Diff。非 Git 目录用文件摘要核对声明的产物。声明路径必须属于本次变更，预览和导出按登记的 SHA-256 校验当前文件。桌面原生保存对话框或命令行 `export` 明确指定目的地，Host 写入审批和交付回执。导出到新文件，已存在的目的地返回失败回执。[执行账本](../../packages/work-core/src/host.ts) · [产物导出](../../packages/app-core/src/exports.ts)

## 源码运行

在仓库根目录运行 `npm run host:serve`，在另一个终端或 `npm run desktop:dev` 中连接。Windows 默认状态目录为 `%APPDATA%\DeskAI2\host`。两个入口设为相同的 `DESKAI_HOST_DIR` 时会使用指定目录。

```powershell
npm run host:ctl -- snapshot
npm run host:ctl -- watch
```

从快照取出相应标识后，可以通过 `host:ctl -- submit` 提交，`host:ctl -- diff` 查看某次执行的统一 Diff，`host:ctl -- export` 指定产物 ID 和绝对导出路径。`npm run host:ctl -- shutdown` 请求停止独立 Host。桌面退出后可继续用命令行查看任务。

## 验证结果

- **真实 dsh 与 Electron** 在临时 Git 项目中提交两条真实任务。强制退出 Host 时两条任务仍在运行。重启后新的 dsh 进程读回原会话日志，两个原 Attempt 均为 `interrupted`，其中一个附带 `WORK_TOOL_OUTCOME_UNKNOWN`。随后用显式继续命令，两条任务使用原会话和各自原 worktree 完成。退出和重开 Electron 后从渲染端读到了相同任务 ID。另一项本机探针以相同连接记录重新认证并调用了仍存活的 dsh 进程。[本地报告](../../outputs/host-validation/host-cde-20261112.json)
- **归属与导出** 两个 Work 分支和目录不同，源目录原有改动保留。续跑的统一 Diff 显示 `ALPHA` 到 `OMEGA`，排除了该次执行前已有的未提交文件。已登记文件可预览，内容改动后旧记录的预览校验失败。导出文件内容正确，重复写同一路径返回 `EEXIST`，命令行可查到包含 Attempt ID 的回执。非 Git 的本地夹具也验证了重叠目录的单写者和已有文件的声明过滤。
- **基础冒烟** Luna Max 完成 `desktop:build` 和隔离状态目录下的 `desktop:dev -- --dialogue-smoke`，11 项通过，使用本地模型夹具。桌面退出后命令行仍可访问同一 Host。10 项相关回归通过，其中断线历史分页、结果未知和请求不重发使用原生协议形状的夹具。[本地桌面报告](../../outputs/desktop-validation/m2/desktop-smoke-1794414985845.json)
