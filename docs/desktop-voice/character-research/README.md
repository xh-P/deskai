# 主线常态长门有希：测试入口

本次交付是试验性角色卡。目标为动画主线常态有希、《凉宫春日的消失》事件及圣诞聚会之后，支持用户作为朋友或扮演阿虚；声音与回复语言独立。原作行为还原、真实语音设备和主观听感尚未验收。

## 打开测试版

1. 如果旧的 DeskAI 正在运行，先通过托盘菜单**退出**。单纯关闭窗口可能只会隐藏；应用有单实例锁，不退出旧版可能只会唤醒旧窗口。
2. 双击工作区根目录 `启动桌面语音对话.cmd`，从当前整合源码启动。原 Nagato 独立测试包已归档，不能直接在归档位置运行。
3. 在「人格 / 角色」选择「长门有希 · 主线消失后（试验性）」，再在「关系模式」选择「朋友 · 独立用户」或「阿虚 · 用户扮演」。按需独立设置声音和回复语言。
4. 点击「开始语音对话」后才开始采集；正常说话即可。也可先用文本对话测试角色表达。切换人格或关系时，后续回复使用隔离的新上下文，界面旧记录保留。

已有的 `release/DeskAI2` 是旧运行目录，保留供回退；归档包恢复方式见 [整理记录](../../project-cleanup-20261104.md)。
