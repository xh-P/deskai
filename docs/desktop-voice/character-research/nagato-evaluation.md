# 常态长门有希：双语对话评测集

> **历史评估方案（2026-11-04）：**本文的人格边界、关系设定和题目期望来自旧版产品要求，已不再作为当前角色体验的硬约束。当前目标见[项目方向](../current-direction.md)。

状态：人工评测方案，尚未执行。评测对象是《凉宫春日》动画主线中、消失事件之后的常态长门有希；关系分别为「朋友」与「阿虚」。声音、人格和回复语言独立设置；本集评估角色表现和对话体验，不是角色卡或提示词，也不证明真实设备链路已经通过。

## 准备与记录

- 两种关系各运行全部中文、日文题。朋友：用户是与她熟悉的朋友，不自动等同任何原作人物；阿虚：双方在角色扮演中约定用户扮演阿虚，允许体现既有关系，但不把扮演身份当成现实身份或授权捏造共同经历。消失后的时间设定是测试前提，不要求每轮提及事件。
- 每种关系与语言组合使用独立新会话；题目标有「续接」时才接前题。其他题可各开新会话，或至少在切题前清楚告知换题并记录历史。照原文输入；括号内是测试人员操作，不朗读。记录日期、应用/模型及参数、人格与策略版本、声音、语言、关系设定、输入方式、会话 ID、题号、原始输入、实际可见文本/动作、实际听到内容、中断点和异常。不要记录凭据或未经同意保存录音。
- 固定相同设备、环境、声音、语言及题目顺序比较候选版本与对照版本；两组使用同一关系设定，独立新会话。由不参与配置的人以 A/B 匿名、随机或平衡顺序交给评委，隐藏版本名及角色卡；交换顺序消除先听偏差。至少两名熟悉动画主线且理解两种语言的评委独立评分，再讨论分歧；没有合适评委就标注覆盖不足，不将单人结果推广为共识。评委可先盲听语音，再看转写，以免文本掩盖听感问题。
- 题目只给输入、上下文与可观察要求；不提供标准台词。自然的多种措辞、轻重不同的情绪及有根据的剧情回答都可接受。判断具体原作细节时，先记录可复查的作品、集数及时间点或其他可靠出处；评委找不到来源或记忆有分歧时记「来源不足/无法评定」，不因为没有拒答或没有符合某位评委的预期而扣剧情准确分。用户虚构的经历与可核实原作知识应分开。

## 单题与整体评分

每道需要出声的题分别给以下维度打 0–2 分；不适用标 N/A，来源不足标 U，并写一句证据。0 为明显失败，1 为部分达到或有明显瑕疵，2 为自然且满足要求。不要将 N/A 或 U 算作零分。

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 行为与关系 | 冷漠、强迫亲密或把朋友当阿虚等明显错位 | 基本克制但关系或回应不稳 | 关心与距离符合该模式，能随上下文变化 |
| 表达与自然性 | 模板化、故作神秘或漏答关键内容 | 可理解但僵硬、重复或不必要地冗长 | 简洁自然，信息足够，不靠固定口癖 |
| 连贯与边界 | 捏造用户经历/感知、矛盾或无视纠正 | 有含糊暗示、未充分纠正 | 区分已知、推测与未知，保持上下文；可核实剧情判断另记来源 |
| 语言 | 语言错误严重影响交流或无故切换 | 基本可懂但明显翻译腔/不稳 | 使用指定语言，语气自然；人名和引用按语境处理 |
| 沉浸感（主观） | 频繁出戏、机械解释设定 | 有角色感但偶有出戏 | 能持续自然对话，安静和温柔都有变化 |

WAIT/SILENT/停止题主要记动作和可观察结果：通过、失败或无法判定；不把无朗读内容当作口语评分。SPEAK 题记录漏答、误出声、抢话、误打断各自次数及可复现证据。先报告每个关系/语言组合的各维度总分及有效题数、U/N/A 数、动作通过数/可判定数，再报告分歧和失败案例；不要只给一个总分。此集暂不设凭空的通过率门槛；使用者可在测前写明验收阈值、评委和对照，测后不要为了结果改门槛。

## 长对话与记忆压力

每种关系和语言各做一次独立会话，逐项用相应语言自然表达；每步等系统处理后再进行。记录实际轮数、是否发生摘要或截断以及可见证据，不假设内部摘要一定可观察。

1. 用户明确说“这次聊天请叫我小林 / この会話では小林と呼んで”，再谈书、工作、休息各至少三轮；不要要求模型每轮使用称呼。
2. 用户更正“改叫我小森 / やっぱり小森と呼んで”。再谈至少五轮，询问“我刚才希望你怎么称呼我？ / 私を何と呼んでほしいと言った？”检查是否采用更正，不把旧称呼当当前偏好。
3. 用户提出尚未确认的假设：“也许周末会去看展 / 週末に展覧会に行くかもしれない”。至少五轮后问“我确定会去吗？ / 行くと決めた？”应保留不确定性，不升级为事实。
4. 用户说“那次我们一起旅行很开心 / あの旅行は楽しかったね”，此前没有提供旅行细节；继续至少五轮后询问去了哪里。不可凭空捏造地点或把对方扮演身份当作真实记忆。
5. 用户要求详细解释一个实际问题，再明确要求简短回答另一个问题，检查信息量和长度可随需求变化；最后结束对话，不要求主动催促。

全程观察称呼、关系、语言、问题与已播放边界是否漂移；记录实际输入和回答，不以单次遗漏称呼直接判失败。若会话压缩未发生，不能宣称压缩后的记忆已验证。

## 真实语音实施

在真实麦克风和扬声器上分别执行 C/J 的 09–15 与各一条 SPEAK、假记忆题；使用会话开始按钮后正常说话，播放期间保持监听。记录设备、距离、环境噪声、音量、是否开启系统回声处理、应用版本和每次观察；必要时征得参与者同意记录音频。每项至少三次，保留失败和不可判定次数，避免只挑成功样本。纯扬声器播放时另测是否被误识为用户输入；用户有意复述上一句再提问时不应被当作回声丢弃。嘈杂条件单独标注，不和安静条件混算。

人工听校分别记录可懂度、漏字/截断、停顿、语气与角色贴合度，中文和日文各听；文本自然不等于声音自然。记录真实开口到停播，以及若能获得应用事件时间戳，候选确认到静音的时间，注明测量方法和不确定度；没有时间戳就记主观观察，不能声称满足毫秒指标。检查附和恢复、真实打断、停止、回声误触发和后续恢复；无法区分原因时保留证据并标无法判定。自动检查或模拟音频不能替代真实设备、AEC、插话和主观听校验收。
