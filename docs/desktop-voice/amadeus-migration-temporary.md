## 整体架构

- 单一麦克风采集 → 回声处理 → Silero VAD → 可配置两阶段端点 → Wake / Conversation ASR 路由 → 对话协调 → Chat Provider → 文本分段 → 原生流式 TTS → PCM 播放。
- Wake 负责唤醒词与空闲退回，Conversation 负责完整识别；两者共享采集，独立选择后端。输出期间不进入待机。
- 端点采用约 160 ms 静音投机识别、350 ms 确认；续说时撤销旧识别并保留完整音频，参数集中配置。
- 普通 Chat 直接流出回答，不强制三态协议；保留取消、轮次隔离与实际播放记录。Provider 与回应协议分离。
- 回声处理和插话分层：播放参考用于回声消除，近端 VAD 用于打断；是否实现显式 WebRTC reverse reference 要以可运行代码及依赖为准。
- TTS 按后端原生产出发送 PCM；版本及音色资源显式配置，取消传播到合成和播放，不把网络切块当成流式生成。
- 主进程只负责组合模块和生命周期；配置、模型路径、服务地址放在配置边界，不散落在业务逻辑中。

## 实施与验收记录

1. **监听 / 唤醒**：开启语音后等待“有希”或“长门有希”，支持唤醒词后直接跟问题；唤醒后连续对话，180 秒空闲退回。输出和用户说话期间续期；停止会话释放识别服务。
2. **ASR / 端点**：Wake 使用 SenseVoice；Conversation 默认本地 Qwen3-ASR 0.6B（已安装隔离环境与模型），也能配置外部转写服务。160 ms 投机、350 ms 确认，续说恢复完整 PCM 并丢弃旧结果。配置见 `config/voice/input-runtime.json`。
3. **AEC / 插话**：已实现 WebRTC AEC3 WASM 播放参考路径；独立声源的无物理回声双讲模拟证实其可随参考时序严重误抑制近端首句。现提供 `off`、`browser`、`browser-ns`、`webrtc`、`webrtc-ns` 处理档位，默认 `browser-ns` 保留原 Chromium AEC+NS 路径；WebRTC 两档仅供实验。帧、时序、量程、上游差异与复现数据见 [AEC 专项核对](./aec-study-20261104.md)。插话候选 / 确认改为可配置 64 / 96 ms，取消传播到生成、合成及播放。
4. **Chat**：改为自然语言正文流，不再要求模型输出三态 JSON 头；Chat Provider 与 ASR/TTS 分离。默认继续使用已有 dsh 模型账号，可配置 OpenAI-compatible 服务，凭据使用环境变量。独立 Work 任务系统不在本轮语音链路中实现。
5. **TTS**：已有有希等 v2 音色启用 GPT-SoVITS 原生语义分块生成；流式开关、块长、重叠长度可配置。按用户确认继续使用 v2，不迁移 v3。

- 本机 RTX 4060：v2 日语合成热启动首块约 0.758 秒，3 个生成块，完成约 2.184 秒；播放层仍保留末尾块等待成功，这不是端到端首声测量。
- Qwen + TTS 共驻留时显存总占用约 5440 MiB，公开中文示例转写约 1.09 秒；一次并行合成和转写通过。不是峰值显存或持续压力测试。
- Qwen 冷加载约 16–18 秒；常驻模式在开麦前与 TTS 并行准备，避免首次说话期间排队。默认 `idlePolicy: resident` 保留模型避免反复冷加载；可选 `unload` 退待机卸载。此处不同于上游的显存→内存迁移，尚未实现该迁移。
- 构建通过；108 项回归和 2 项新增 Chat 流测试通过。Electron 对话界面烟测通过，AEC Worklet 确认收到播放参考并运行；实验 AEC 路径的首句从“你回来了”误识别为“嗯”，已通过原始 / 处理后音频对照定位为近端误抑制，因此未将其作为默认交付。恢复浏览器 AEC 后，同一模拟输入首句匹配、两次会话识别均通过。上述结果不代表真人麦克风、外放双讲、音质或延迟验收。
- [真实模型全链路报告](../../outputs/desktop-validation/m3/desktop-smoke-1793744288912.json)：Qwen → dsh 真实模型 → v2 GPU TTS → 模拟播放通过；10 个 PCM 块、3 段完成播放、0 次 TTS 失败。测试输入包含停顿，允许多轮提交，仍检查模型请求数不超过确认输入轮数。
- [目录包检查](../../outputs/desktop-validation/m4/package-smoke-1793744418000.json)通过：打包启动、资源定位、托盘和关闭隐藏均正常；该检查不打开麦克风、不调用模型。

## 验收入口

- 运行 `release/DeskAI2-Amadeus/DeskAI.exe`，点击开始语音，等待模型准备，然后说“有希，……”；后续直接说话即可。首次准备约 16–18 秒，具体以本机状态为准。
- 用耳机与外放分别检查首字、续说、插话和声音连贯性；短端点可能更早拆分停顿，参数均在输入配置中。
- 本次目录包复用工作区的模型和隔离 Python 环境，不是可脱离资源目录拷走的独立安装包。目录包内 `resources/app/config/voice/` 是实际运行配置；源码配置变更后需重建目录包。
