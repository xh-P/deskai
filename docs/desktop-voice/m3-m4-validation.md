# M3–M4 实现与验证

更新：2026-10-30。M3 逐句 TTS/换声与 M4 桌面功能已接入；本报告将代码、自动验证与人工门禁分别记录。物理麦克风、扬声器/AEC 与主观听校尚未验收；不把模拟设备回放当作这些项目通过。

## 启动与操作

- 原工作台：双击根目录 `启动桌面语音对话.cmd`，或 `npm run desktop:dev`。无需分别开三个服务终端。
- 可运行目录包：`npm run desktop:package` 生成 `release/DeskAI2/DeskAI.exe` 与 `启动DeskAI.cmd`。包携带 Electron、受支持的独立 Node、编译应用及生产依赖；原素材、模型、Conda 和 GPT-SoVITS runtime 作为外部资产，应用旁 `deskai-runtime.json` 的 assetRoot 指向它们的共同根目录。相对路径以包目录为基准，没有开发机绝对路径。
- 打开窗口即预热本地 ASR/TTS，显示真实准备/下载/错误状态，不打开麦克风、不调用对话模型。点击“开始语音对话”后才授权并自动监听。
- 默认常态有希 v2 / ref-01；可以独立选择十角色、参考语气、人格和回复语言。输入/输出设备、音量、语速和关闭行为会保存。输入设备在下次开启麦克风时生效。
- “暂停麦克风”保留文字会话；“停止回复”清除未播音频和取消生成；“结束会话”释放采集。关闭窗口默认隐藏到托盘，托盘标明是否监听；退出用托盘菜单。系统睡眠结束会话，唤醒后需重新开始。
- 合成失败保留文字，点击“恢复语音服务”重建自己 worker；dsh 失联停止采集，可重新开始。无设备、拒绝权限、设备移除、VAD 超载均有可恢复提示。原 Web、训练和试听入口未改动。

## M3 实现

`services/tts` 与 `packages/tts-adapter` 管理认证 loopback worker，v2、FP16、CUDA Graph、batch 1，GPU 请求和成套换权重串行。每次成功预热后才变更 voiceRevision，失败尝试回滚。取消当下主进程屏蔽旧 PCM，后台 CUDA 收尾后才接下一次推理。

`SentenceStream` 安全清理代码、纯 URL、动作和 Markdown，保留原文区间用于账本；三语标点、英文小数和缩写有回归。`SpeechOutput` 最多一项合成在运行、两句音频驻留，每句最多 30 秒。完整短句 PCM 接收后切为不超过一秒的播放块，按真实采样率播放；目标 3 秒前瞻，worklet 硬限 6 秒，未收到接纳回执不继续发送。暂停保留位置，确认取消/换声清除缓存，旧 generation/attempt/voiceRevision 与重复块均拒绝。

逐段完成回执只表示 AudioWorklet 的估计播放，不证明人实际听到。语音历史只投影已完成的可读句子；部分句仅记身份，不猜已听字数；未播生成原文不进入下一轮。问题必须等末段播放完成才成为待回答状态。纯文字模式按 DOM 显示确认交付；语音会话中的文字发送仍可语音回复。

## 已执行的自动验证

- 全套确定性测试：`npm run desktop:test` 最终 74/74 通过；覆盖 ASR 边界/合并、协议、EOF 末行、取消、dsh transport、TTS IPC、播放回执、模型路由和偏好。新增 M3 回归还包含 100 轮固定取消/换声交错，0 次旧段交付。模拟时序不等于真实设备压力验收。
- Python worker：9 项通过，含资源/参考登记、认证、取消、回滚故障注入和断连退出。
- 真实 GPU：十声音逐个成套加载、预热、短句生成，另有备用 ref-02、三次取消和常态有希恢复，全部通过。12 个 WAV 与详细数据在 `outputs/desktop-validation/m3/tts/`。实际均为 32 kHz 非静音，时长 1.08–3.36 秒；短句合成 0.592–4.022 秒。取消后台收尾 2.69–4.05 秒；恢复默认声音的 WAV SHA256 与换声前一致。48 kHz 由协议/播放器测试覆盖，未冒充现有模型的实际输出。
- Electron 贯通：`npm run m3:smoke` 通过。模拟麦克风 → 真实本地 SenseVoice → 明示的模拟模型 → 真实 GPU v2 → AudioWorklet；553 帧输入，其中播放期间继续采集 118 帧，一次模型接口调用，3 个短句/5 个 PCM 播放块逐个完成，账本未播为空，末尾问题在播放后生效。产物：`outputs/desktop-validation/m3/desktop-smoke-1793303528267.json` 与截图。此命令静音运行，不证明物理扬声器/AEC。
- M2 模拟界面回放通过；模型头隐藏、WAIT/SILENT无气泡、文字交付确认、取消/重试和人格/语言独立设置保持有效。
- 真实模型贯通：`node scripts/desktop/launch.mjs --tts-smoke --real-model` 通过；仍使用模拟麦克风，但 ASR、dsh 配置的真实模型、GPU v2 和 AudioWorklet 均为实际接口。818 帧输入、播放期间持续采集 295 帧，1 次模型请求/1 个 attempt/1 次用量事件，4 句/11 个 PCM 播放块全部完成、未播为空。产物：`outputs/desktop-validation/m3/desktop-smoke-1793303857461.json`。ASR 短片段自动语言识别仍可能有文字偏差，不将固定样本的字面前缀一致性作为通过结论。
- 真实模型文本语义：EOF 协议适配和拒绝继续规则修复后，39 PASS / 0 FAIL / 0 INVALID / 18 UNTESTED，含 27 次实际模型调用；中/日/英各 13 条通过。完整逐例结果见 `validation/m2-semantics-real.json`。18 条仍需输入持续、声学或权限证据，不宣称通过。
- 可运行包实际启动：`release/DeskAI2/DeskAI.exe --shell-smoke --unhandled-rejections=strict` 通过，`app.isPackaged=true`、真实托盘建立、关闭主窗口后隐藏、外部资源查验均通过；不打开麦克风或请求模型。验证时修复托盘销毁后退出仍更新托盘的竞态；最终产物：`outputs/desktop-validation/m4/package-smoke-1793304448894.json`。复制到其他机器运行尚未测试，仍需兼容的 NVIDIA/CUDA 环境及外部资产。

## 限制与待人工协助

- 真正的账号路由已修复；三语真实模型语义复测及协议适配结果单列于 [M2 真实验证](./m2-live-validation-20261030.md)。真实请求成功不等于全部语义门禁通过。
- 逐句合成尚不是单句内部低延迟 PCM 流；现有短句测量包含超过一秒的情况，未达到所有性能目标。没有将 TTS 单项时间写成端到端首声时间。
- 回滚以故障注入单测验证，未破坏现有权重来制造实际 GPU 加载失败。OOM 提示和手动重建已实现，未故意占满显存做破坏性测试。
- 真实麦克风、输出设备切换、扬声器 AEC、耳机/外放自然插话、主观听校、30 分钟连续对话、20 次真实换声和完整三语自然对话仍未完成。M5 保留未完成。
- 需要用户协助的具体事项集中在 [临时清单](./temporary-user-checks.md)。
