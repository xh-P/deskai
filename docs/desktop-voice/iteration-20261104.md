# 本轮架构与实施记录（临时）

## 已确认方向

- 本轮继续迭代源码，不制作目录包或安装包；每轮完成提交并推送。
- 默认中日文唤醒“长门 / 有希 / 长门有希”，兼容日文汉字与假名，支持界面配置。
- Qwen 显存保持驻留，TTS 继续 v2。

## 整体架构（实施前确定）

1. 默认参数在运行配置中；用户修改写入应用偏好。唤醒门控和音频模块只接收规范化参数，不包含角色名字判断。
2. 修改唤醒词后作废旧识别路由；AEC 档位切换在明确的采集生命周期边界生效，界面显示当前配置与生效要求。
3. AEC 策略独立于 VAD、ASR 与播放器。播放参考取实际音量后的 PCM；逐项核对 Amadeus 的帧长、格式、采样率、延迟、双讲处理及后端参数，实验结果与物理设备效果分开记录。
4. Chat 沿用语音专用 dsh Host；Work 复用本地已安装 Harness 的原生 Web Host/UI，保留原生工具授权、问题询问、历史与恢复。应用只管理入口和自己启动的进程，不复制工具执行逻辑，不修改用户权限设置。
5. 维护当前文档入口；过期方案和上轮临时报告转入历史索引，避免旧约束混入当前说明。

## 实施结果、验证与待答复

- **唤醒**：设置界面可编辑、保存、恢复默认；中文长门 / 有希 / 长门有希及日文長門 / 有希 / 長門有希、假名变体均来自默认配置。用户覆盖保存在应用偏好中，保存立即生效并作废旧识别路由，不重置连续对话。
- **显存 / TTS**：Qwen 保持 resident，TTS 继续 v2，未新增安装包或目录包。
- **AEC 档位**：关闭、浏览器回声消除、浏览器回声消除加降噪、实验 WebRTC、实验 WebRTC 加降噪。默认浏览器加降噪，修改后重开麦克风生效。后端没有开放可调 AEC 强度，因此不伪造“弱中强”旋钮。源码差异、独立声源与参考时序复现见 [AEC 专项记录](./aec-study-20261104.md)。
- **Work**：桌面按钮打开本机 Harness 原生工作台，保留原生工具、权限、历史和提问界面；配置 `config/work-runtime.json` 决定 profile 与启动目录。关闭窗口只隐藏；退出 DeskAI 才终止自己启动的 Host。普通语音 Chat 仍独立，不自动把语音指令转成任务。
- **文档**：更新根 README 与当前索引；旧交接改为历史概览，上轮临时报告保留为历史证据，不再列为当前待答复。
