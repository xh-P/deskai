# 桌面 AI 语音对话：实现交接

更新：2026-10-30。状态：**M3 逐句合成、播放账本与十声音切换，M4 托盘、设备/偏好、恢复和目录运行包已实现**。开发入口为根目录 `启动桌面语音对话.cmd`，目录包入口为 `release/DeskAI2/DeskAI.exe`。真实 GPU 十声音和模拟麦克风的桌面 ASR/TTS 贯通通过；账号路由已修复，真实模型语义结果单列。物理麦克风/扬声器/AEC、听校和 M5 完整门禁仍未通过。参阅 [M3–M4 运行与验证](./m3-m4-validation.md)、[真实模型验证](./m2-live-validation-20261030.md) 和 [临时协助清单](./temporary-user-checks.md)。

## 已确认需求

- Windows 桌面应用；Electron + React + TypeScript 为选定方案。
- ASR 使用本地 dsh 的 SenseVoiceSmall；对话通过 dsh；TTS 使用已有 GPT-SoVITS v2 权重。
- 默认声音为常态有希；支持切换现有角色声音。本阶段不训练模型、不默认切到 v5。
- **自动监听、自动断句、自动识别与发送**，不是默认按住说话。进入语音会话时开启麦克风，关闭会话即停止采集；不在应用启动后未经用户操作就开始录音。
- AI 播放时仍监听，用户可以自然插话；回声处理和误打断控制属于首版验收。
- **AI 并非每听见一句就必须回复**：区分继续说话、对 AI 发问、简短附和、思考、自言自语及背景声。
- 系统提示词、角色设定、声音和语言分别配置，不把参考音频自动当作人格设定。
- 多 Agent 可自主按需调度：简单重复工作使用 Luna Max，复杂工作最多 Sol High，禁止 Astra；细则见 [协作说明](../agent-collaboration.md)。不频繁播报或轮询。

## 主要决策

- 自动语音为主，按钮仅用于开始/结束会话、手动停止和恢复。首版不能退化成播放期间关闭麦克风的半双工产品。
- 先用声学 VAD 判断候选边界，再根据内容判断是否轮到 AI；VAD、ASR 和是否回应是三个不同问题。
- 本地规则处理明确事件；有歧义时用**一次模型请求同时完成回应决策与回复生成**。不固定串联“判断 LLM + 回答 LLM”两次调用。
- 默认没有“沉默几秒就主动找话”的定时器；WAIT 不自动重试模型。用户继续说、明确催促或点击发送才推进。
- 默认保留常态有希声音；建议人格默认使用轻量常态有希风格（冷静、简洁、温和），提供普通助手切换。此人格是产品建议，不等于用户已指定完整剧情扮演。
- 先建立专用 dsh Web profile/preset，不修改现有通用 dsh 配置。已有登录通过 dsh 的受支持方式复用，不复制或输出凭据。
- ASR CPU 常驻，TTS GPU 单声音常驻；一键管理进程。原始录音默认不落盘。

## 已知事实与待核实事项

本地 `@deepseek-ai/dsh` 为 `0.2.1-rc.2`。SenseVoice Provider 使用 CPU、INT8 ONNX 与 Silero VAD；Remote 接受完整的 16 kHz 单声道 PCM16 WAV，不提供逐字转写流。会话服务有 `prompt/follow/cancel`，`follow({assistantStream:true})` 能给出增量帧。preset 支持 `plugins: []`，但实施时仍需验证最终工具清单及有效系统提示词，不能仅凭配置名字推断。

现有10角色的 v2 GPT/SoVITS 和参考路径已核对。M0 常态有希 v2 的 GPU 合成/认证 IPC/取消恢复检查通过，但不等于十角色加载或主观听校通过。SenseVoice 三语文件转写与 M1 Electron 模拟回放已通过；声卡延迟、AEC、自然插话真实设备和整条对话链路仍须验收，见各阶段报告。
