## 之后可由你执行的实际检查

1. 双击 `release/DeskAI2/DeskAI.exe`，先用耳机开启语音会话，正常说话、停顿、接续和短回答；确认首字、转写及逐句声音。
2. 播放中说新问题或“别说了”；再测试短促咳嗽、“嗯”和键盘声，确认误打断时从未播位置恢复。测试期间麦克风应保持监听。
3. 使用扬声器重做：至少 20 次自播无输入应不形成回复环；10 次真人插话记录取得话权次数。若外放自激或误打断，请记录输入/输出设备名称和场景，先使用耳机。该项尚未通过 AEC 验收。
4. 从声音/语气选择器切换试听；自动生成的十二段 WAV 在 `outputs/desktop-validation/m3/tts/`。听校是否漏字、语气是否自然以及角色是否选对；自动 RMS/哈希检查不能代替此项。
